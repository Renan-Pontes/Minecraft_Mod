# Isekai Mahou v1.6 — "Profundezas" (contrato)

Mod NeoForge 1.21.1 (Java 21, Mojang + Parchment, GeckoLib 4.9.3, Curios, SmartBrainLib, playerAnimator). Jogador/dono: Renan (PT-BR).
**Leia primeiro `docs/ARCHITECTURE.md`** (regras de módulo, núcleo, glifos, ids, arte) — vale tudo de lá, exceto o que este arquivo mudar.

## Pedido do jogador (traduzido)
> Hoje ninguém tem motivo para ir ao subterrâneo, ao Nether ou ao End. Crie coisas lá que justifiquem explorar:
> masmorras, torres, cidade dos anões, cidadela demoníaca, biblioteca do End, chefes, materiais novos.
> Também: coisas de anime simples mas que chamem atenção; alguns biomas mais planos, bons para cidades;
> "Inventário Dimensional"; mais portais — "se dá para construir um portal, dá para abrir com magia também".
> Os materiais novos devem ser VALIOSOS, mas NÃO obrigatórios para progredir (o jogador escolheu assim).

## O que já existe (não refaça — reaproveite)
- **Chefes:** `core/boss/BossKit` (escala de grupo, arena, `leapAt`/`blinkNear` anti-trapaça, `roar`, `shake`, `flash`), `core/boss/Telegraph`, `BossRewards`, `core/api/BossArena` (arena INQUEBRÁVEL enquanto há luta), `core/api/BossThemed` (música), entrada com letreiro (`feature/boss_music/BossEntrance`, automático para quem está na tag `c:bosses`). Modelo de módulo de chefes: `feature/bosses_g/**` e `feature/bosses_f/**`.
  - Música: implemente `BossThemed.musicTheme()` devolvendo um tema EXISTENTE (`abyss_sovereign, beast, elemental_guardian, generic_boss, hollow_king, lich, mimic_king, primordial_dragon, seraph, twilight_herald...` — ver `assets/isekai_mahou/sounds/music/`). Não gere áudio.
- **Estruturas:** jigsaw + moldes `.nbt` gerados por `tools/structgen.py` (classe com `fill/hollow_box/cylinder/chest/spawner/jigsaw/entity/save`). Exemplos: `worldgen/structure/forgotten_crypt.json` (subterrânea), `hydra_lair.json` + `structure_set/hydra_lair.json` (posicionamento `isekai_mahou:random_spread_multi` com `exclusion_zones` de cidades — USE ISSO no Overworld). Tags de bioma `tags/worldgen/biome/has_structure/<id>.json`. Covil com chefe: veja como `feature/world_v09` e `feature/bosses_g` fazem o chefe surgir.
- **Nether/End:** nada do mod gera lá hoje (só Slimes de Fogo e Diabretes nascem no Nether). Para o Nether use `random_spread` normal, altura fixa/`start_height` e checagem de chão; para o End (ilhas externas, biomas `end_highlands`/`end_midlands`) faça um `Structure` próprio cujo `findGenerationPoint` só aceite terreno sólido (não gerar sobre o vazio) — veja `feature/cities/world/CityStructure` como exemplo de tipo de estrutura próprio.
- **Minérios/features:** exemplo `worldgen/configured_feature/mana_vein_ore.json` + `placed_feature` + `neoforge/biome_modifier/*.json` (NeoForge `add_features`, tags `#minecraft:is_overworld`, `#minecraft:is_nether`, `#minecraft:is_end`).
- **Rota/diário:** cada pasta `data/isekai_mahou/journal/*.json` é lida (ex.: `las_noches.json`). Condições: `flag, counter, bosses, visit, level, circle...`; `locate` aceita `{"structure": id}`, `{"place": id, "dimension": id}`, `{"biome": tag}`.
- **Relíquias de raça** já existem: `relic_dwarven_rune`, `relic_demon_horn`, `relic_dragon_scale`, `relic_seraph_feather`... (feature/character). Use como DROP raro pelo id.
- **Viagem:** `core/api/Travel` + `core/api/Places` (tipos `dimension_hub`, `waystone`). Contador do núcleo `visit.<ns>.<path>` por dimensão visitada (ex.: `visit.minecraft.the_nether`).
- **Essências:** `CoreRegistries.ESSENCES` (arcano + 6 base). Pergaminho de glifo: `CoreRegistries.GLYPH_SCROLL` + componente `GLYPH`.

## Regras comuns (TODOS os agentes)
- **Texto:** tudo que o jogador vê em PT-BR (+ `en_us`), por `Component.translatable`, em `src/main/lang/<modulo>/{pt_br,en_us}.json`. Comentários em PT-BR.
- **Nunca rode gradle.** Compile com `bash tools/check-module.sh <modulo>` (precisa terminar "TUDO OK"). Não referencie classes dos OUTROS módulos novos desta versão (eles estão sendo escritos agora) — só por id em texto. Classes do núcleo e de módulos antigos já compilados podem ser usadas se compilarem.
- **Dono:** edite só o que é seu (tabela abaixo). Arquivos compartilhados de dados (tags de bioma/bloco/entidade, `c:bosses`, `mineable/pickaxe`, `needs_diamond_tool`...) vão em `src/main/merge/<modulo>/<caminho normal>`. Precisa de algo fora? liste em **PEDIDOS**.
- **Mundos salvos:** nunca renomeie/remova ids existentes. NBT novo opcional com padrão.
- **Desempenho:** nada de varredura grande por tick; estruturas só com moldes (sem colocar milhares de blocos em runtime); spawns em estruturas com limite; só chunks carregados.
- **Balanço:** upar até o 100 continua DIFÍCIL; poder absurdo só perto do 100. Equipamento novo: Mithril ≈ entre diamante e netherite, Adamantita ≈ netherite+, Estelar = topo (exige Círculo alto para usar/forjar). Chefes novos: vida e dano no nível dos chefes da v0.9/v1.0 de mesmo "andar" (Nether ≈ Círculo 5–6, End ≈ 7–8, masmorra varia por andar).
- **Obtível em survival:** todo bloco/item tem receita ou fonte real (loot, drop, troca) + aba criativa; todo glifo tem caminho de desbloqueio (pergaminho em loot de estrutura/chefe, como os glifos comuns hoje). Texturas por `tools/pixelart.py` em `tools/gen/<modulo>.py` (pixel-art no estilo atual, 2–3 tons). **Nunca** rode o `tools/gen/icons.py` completo. Ícones de glifo: veja `feature/ui_grimoire/client/GlyphIcons` e como `tools/gen/auto_glyphs_icons.py` fez.
- **Modelos:** criaturas/chefes em GeckoLib (`.geo.json` + `.animation.json` à mão, formas reconhecíveis). Itens de anime: modelo de item 2D ou 3D simples.
- **Chefes:** tag `c:bosses` (merge), `BossKit` (escala de grupo + arena + anti-inalcançável), `BossArena` (arena inquebrável na luta), golpes telegrafados (`Telegraph`), ≥2 fases, `BossRewards`, comando de teste. Drops únicos + relíquia de raça rara quando fizer sentido.
- **Diário:** cada área tem um capítulo OPCIONAL próprio em `data/isekai_mahou/journal/<modulo>.json` (formato de `las_noches.json`), com `locate` para a estrutura, passos de visitar/explorar/vencer o chefe e XP. `order` reservado na tabela.
- **Debug:** comandos op `/mahou <modulo> ...` (dar itens, `tp`/`locate` para a estrutura, invocar chefe, encher algo).
- **Relatório final (inglês, curto):** arquivos; ids novos (uma linha cada); como testar (comandos); lacunas; PEDIDOS.
